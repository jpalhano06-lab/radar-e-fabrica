# Radar e Fábrica

Os dois lados do produto num repositório só:

- `radar/` — o Radar de Canais: fila, roteiro pela assinatura, thumbnail, Trello e custos (antes em `jpalhano06-lab/Radar-de-Canais`).
- `fabrica/` — a fábrica de vídeos: cenas, imagem, narração, render e vigia (antes em `zhek00/backend-editor`).

O histórico dos dois veio junto. Chaves, tokens e dados locais (`.env`, `youtube_contas.json`, `dados/`, bancos e logs) ficam fora do Git: cada pasta tem o seu `.gitignore`.
